## 🚀 What is GlobeTalk?

GlobeTalk solves a problem that WhatsApp and Telegram haven't elegantly solved: **real-time, per-recipient, server-side message translation in multilingual group chats.**

When Alice (English) sends a message, Bob (Hindi) receives it in Hindi and Carlos (Spanish) receives it in Spanish — **before the message even reaches their screen**, translated inside the Socket.IO delivery pipeline. No one has to manually translate anything.

Built as a Master's-level final year project demonstrating applied AI, real-time systems design, and full-stack engineering.

## ✨ Features

### 💬 Core Chat
- ✅ Real-time 1-on-1 and group messaging via Socket.IO
- ✅ File & image attachments (stored on Cloudinary CDN)
- ✅ Typing indicators with animated dots
- ✅ Online presence tracking (green dot on avatars)
- ✅ Friend request system (send / accept / reject)
- ✅ Group chat creation, member management, and admin controls

### 🌐 Multilingual Translation Engine
- ✅ **Server-side per-recipient translation** — each user receives messages in their preferred language
- ✅ 12 supported languages: English, French, Spanish, German, Hindi, Japanese, Korean, Chinese, Arabic, Portuguese, Russian
- ✅ "Show original / Show translation" toggle on every message bubble
- ✅ Language set at signup and synced to database
- ✅ Rate-limited translation API with batch support
- ✅ The entire login/signup UI translates itself when you change language

### 🤖 AI Features *(In Progress)*
- 🔄 **AI Conversation Summariser** — "Catch me up" button generates a bullet-point summary of missed messages using Google Gemini
- 🔄 **Smart Reply Suggestions** — 3 context-aware chip suggestions above the input, generated by Gemini
- 🔄 **Voice-to-Text Input** — Browser-native Web Speech API, zero cost, 12+ languages

### 🔐 Security
- ✅ JWT authentication via secure HTTP-only cookies
- ✅ Bcrypt password hashing
- ✅ CORS protection
- ✅ Input validation with express-validator

### 📊 Admin Dashboard
- ✅ Protected admin portal with secret-key authentication
- ✅ User management table (MUI DataGrid)
- ✅ Chat and message management
- ✅ Analytics charts (Chart.js): user growth, message volume, active chats

## 🏗️ Architecture

```
Frontend (Vercel)          Backend (Render)           Services
──────────────────         ──────────────────         ──────────────────
React 18 + Vite      ←──→  Express + Node.js    ←──→  MongoDB Atlas
Redux Toolkit               Socket.IO                  Cloudinary (media)
Material UI v6              REST API routes            Google Cloud Translate
Socket.IO-client            JWT Auth                   Google Gemini AI
Framer Motion               Mongoose ODM
```

### Translation Flow
```
Alice types "Hello" → socket.emit(NEW_MESSAGE)
         ↓
Server receives message
         ↓
For each recipient → fetch their language from DB
  Bob (hi)   → translate("Hello", "hi") → "नमस्ते"
  Carlos (es) → translate("Hello", "es") → "Hola"
         ↓
Emit personalised message to each recipient's socket
(originalContent also sent for the "Show original" toggle)
         ↓
Alice sees "Hello" | Bob sees "नमस्ते" | Carlos sees "Hola"
```

## 🚦 Getting Started

### Prerequisites
- Node.js 18+
- MongoDB Atlas account (free)
- Cloudinary account (free)
- Google Cloud API key (for translation)

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/GlobeTalkApp.git
cd GlobeTalkApp
```

### 2. Set up the Server
```bash
cd Server
cp .env.example .env
# Fill in your environment variables in .env
npm install
npm run dev
```

### 3. Set up the Client
```bash
cd Client
cp .env.example .env
# Set VITE_SERVER=http://localhost:3000
npm install
npm run dev
```

### 4. Open the app
Visit `http://localhost:5173`
